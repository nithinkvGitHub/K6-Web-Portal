📖 How to Deploy Across Office EC2 Instances

This architecture runs locally out-of-the-box and scales to any number of remote EC2 load generators:

  1. Native k6 CLI Auto-Detection: When k6 is installed on a worker host, the agent executes native k6 run --execution-segment; otherwise it uses the built-in Measured Node HTTP Engine.
  2. Start Worker Agent on Remote EC2s:
    BIND_HOST=0.0.0.0 PORT=4101 node server/worker-agent.mjs
  3. Optional Security Token: Set AIPERF_TOKEN=secret on both portal and workers to require token authentication.
